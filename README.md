# Домашнее задание #1

Прогнозируем, совершит ли посетитель интернет-магазина покупку. Сравнил LogReg, Random Forest и XGBoost, проверил гипотезы. Финально выбрал XGBoost.

Вся работа в `research.ipynb`, данные в `data/`. Для запуска: `pip install -r requirements.txt`, затем открыть ноутбук в Jupyter.

Датасет: [Online Shoppers Purchasing Intention](https://doi.org/10.24432/C5F88Q).
